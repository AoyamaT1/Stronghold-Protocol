## 一、术语翻译表（先定这个，不然全是白写）

方舟只有四类元素损伤（`server/sim/constants.js` ELEMENT_ORDER）：`神经 / 侵蚀 / 灼燃 / 凋亡`。

| 边狱巴士 | 卫戍协议 | 理由 / 落法 |
|---|---|---|
| **沉沦** | **凋亡损伤** ✅ | 语义与机制双吻合：凋亡损伤的爆发在友方侧是 `spLossPerSec`（扣理智），正对边狱"沉沦扣理智"。 |
| **烧伤 / 燃烧** | **灼燃损伤** ✅ | 方舟原生元素。 |
| **流血** | **【流血】** | 占用 `necrosis` **遗留备用表**（官方内容零使用，零冲突），改名 + 换血系图标。**别用 `burn`**（炎盟约在用）。 |
| **震颤** | **神经损伤**（爆发 = 麻痹） | 边狱震颤=叠层→**引爆**；方舟元素损伤正是"叠满→爆发"。神经损伤爆发给**麻痹**（`server/sim/constants.js` PALSY_MAX=3，每层抵消一次普攻）——就是"硬直"。震颤引爆 → 神经损伤爆发。 |
| **破裂** | **脆弱** | 方舟无"按层数追加伤害"。破裂的语义是"打中就更疼"⇒ 脆弱（受到伤害提升）。 |
| **呼吸法 / 暴击** | **攻击力提升** | ⚠️ **方舟没有暴击系统**。凡"暴击时"改「攻击力提升」「额外一次攻击」或并入攻击力加成。 |
| **速度值 / 迅捷 / 速度差** | **攻击速度** | 方舟无速度轴，用攻速；"与目标的速度差"这类条件改成攻速差或直接删条件保留加成。 |
| **援护防御 / Protection** | **庇护** | 方舟原生减伤状态。 |
| **弹药类：虎标弹 / 猛虎标弹 / 魔弹** | **方舟弹药系统** | `durationType: "AMMO"`（拉特兰那套）。奥提斯的【魔弹】1~7 层就是 7 发子弹。 |
| **血宴 / 硬血 / 尖钉 / 狂信 / 深泪 / 守护之剑 / 穿刺之剑 / 泪锋 / 棺 / 杜拉罕 / 天究星刀 / 脚力 / 迫近 / 遵命 / 曙光** | **保留原名** + mod 自写 sim | 人格专属资源，方舟无对应物。 |
| **理智值** | **【理智】** | 罪人专属资源，−45 ~ 45，战斗开始 0。正值每点攻击力 +0.5%；负值每点攻速 +0.5%。**罗佳/辛克莱/奥提斯的高理智消耗正好挂这里。** |
| **拼点胜利 / 失败 / 反面命中时** | **删除该条件** | 方舟无拼点、无正反面。 |
| **硬币 N 命中时** | **攻击命中时** | |
| **攻击容量 N** | **同时攻击 N 名敌人** | |
| **恢复体力 X%** | **回复相当于伤害 X% 的生命** | |

⚠️ **现有实现里的非法状态词，必须替换**：`【腐蚀】【破甲】【枷锁】【骨断】【凋零】` —— 都不是方舟术语。
